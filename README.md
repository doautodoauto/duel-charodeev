# Дуэль Чародеев

Игра «три в ряд» для двоих на одном поле (онлайн и против компьютера).

## Как выложить на GitHub Pages
1. Создайте репозиторий и загрузите в корень: index.html, icon.png, manifest.json.
2. Settings → Pages → Source: Deploy from a branch → main / (root) → Save.
3. Через 1–2 минуты игра откроется по адресу https://<логин>.github.io/<репозиторий>/
4. На iPhone/iPad: Safari → «Поделиться» → «На экран Домой» — запуск на весь экран.

## Онлайн
Используется бесплатный публичный MQTT-сервер (свой сервер не нужен). Игроки с одинаковым «кодом зала» и одним сервером в настройках видят друг друга.
Совет: придумайте свой код зала (например family-2026), чтобы в списке были только свои.
Если сервер 1 недоступен — выберите другой в Настройках на обоих устройствах.

Прогресс, история и незаконченный бой с компьютером хранятся в памяти браузера на устройстве.
